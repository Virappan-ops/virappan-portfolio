# Virappan — Developer Portfolio

A small, responsive Next.js portfolio starter using Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `app/page.tsx` with your real email.
2. Add your real GitHub and LinkedIn links when ready.
3. Review project descriptions and remove anything that is not ready to be shown publicly.
4. Deploy to Vercel and test the live site.

This is a starter portfolio, not a guarantee of approval for any third-party subdomain service.
